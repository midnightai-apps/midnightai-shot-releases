# Midnight Shot

Capture your screen and keep images visible in floating overlays for reference and comparison.

This repository hosts official Midnight Shot release downloads for macOS and Windows.

## Downloads

Installers and updates will appear on the [Releases page](https://github.com/midnightai-apps/midnightai-shot-releases/releases) when available.

| Platform | System requirements |
| --- | --- |
| macOS | macOS 14 or later, Apple Silicon |
| Windows | Windows 10 version 2004 or later, x64 |

Use the package for your platform. Releases marked **Pre-release** are for testing.

## Release channels

- Windows: `windows-v*`
- macOS direct distribution: `macos-live-v*`
- macOS test builds: `macos-test-v*`

Mac App Store updates are delivered through the Mac App Store.
